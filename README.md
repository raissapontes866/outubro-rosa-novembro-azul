
# 💗💙 **Outubro Rosa & Novembro Azul – A Prevenção Começa com a Informação**
-

Projeto educativo desenvolvido com o objetivo de conscientizar a população sobre a importância da prevenção, do diagnóstico precoce e dos cuidados com a saúde.

O site aborda as campanhas Outubro Rosa, voltada à conscientização sobre o câncer de mama, e Novembro Azul, dedicada à saúde masculina, com destaque para o câncer de próstata.

O projeto apresenta informações, sinais de alerta, orientações, mitos e verdades e um quiz interativo para incentivar o aprendizado de forma dinâmica.
-
 # **Tecnologias utilizadas:**
 -
- HTML5
- CSS3
- JavaScript
-
# **Objetivo:
-
 promover a informação, incentivar o cuidado com a saúde e mostrar que a prevenção deve acontecer durante todo o ano.
